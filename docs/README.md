# Документация калькулятора

Файл `calculator.html` содержит описания функций модуля `calculator.py`.
Документацию формирует стандартный модуль Python `pydoc` из строк документации
в начале модуля и внутри функций.

## Локальная сборка

Из корневой папки проекта:

```bash
python3 -B -m pydoc -w calculator
mkdir -p docs
mv calculator.html docs/calculator.html
```

Открыть `docs/calculator.html` можно в браузере.

## Автоматическая сборка

Workflow «Документация» запускается при отправке коммитов и при создании
или обновлении Pull Request в `main`. Он заново формирует HTML из кода
соответствующего коммита и сохраняет файл как артефакт `documentation`.

В GitHub Actions нужно открыть нужный запуск workflow и скачать артефакт
из раздела Artifacts. Внутри архива находится `calculator.html`.

В репозитории сохранена исходная HTML-версия. Актуальный результат каждого
автоматического запуска находится в его артефакте; workflow не создаёт коммиты.
