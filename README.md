# Калькулятор

Лабораторная работа №2 по ТРПО. Настройка CI/CD с помощью GitHub Actions.

Приложение выполняет сложение, вычитание, умножение и деление.
При попытке деления на ноль возникает исключение ZeroDivisionError.

## Запуск

Требуется Python 3. Дополнительные библиотеки не нужны.

```bash
python3 -B main.py
```

## Тесты

```bash
python3 -B -m unittest discover -s tests -v
```

В тестах проверяются арифметические операции, дробный результат деления
и обработка нулевого делителя.

## Автоматическая проверка

Workflow `.github/workflows/main.yml` запускается при отправке изменений
в любую ветку и при создании или обновлении Pull Request в `main`.
Он запускает тесты и приложение на Python 3.13.
